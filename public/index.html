Byte 제품군 소개

하나의 계정으로 만들고, 평가하고, 함께 편집하는 학습·창작 도구입니다.

bytenodeAI와 전용 문법으로 수업 자료, 보고서, 프레젠테이션을 빠르게 만드는 콘텐츠 제작 도구.
byteexam문항을 구성해 시험지를 만들고 배포·응시·자동 채점까지 이어지는 평가 도구.
bytetext문서 초안을 함께 작성하고 비교·수정하며 완성하는 실시간 공동 글쓰기 도구.
byteform설문과 퀴즈를 만들고 응답 수집, 자동 채점, 결과 통계를 한곳에서 처리하는 폼 도구.
byteslide템플릿과 자유로운 캔버스로 발표 자료를 직접 디자인하고 내보내는 프레젠테이션 도구.
bytewiki수식과 그래프, 위키 링크를 활용해 지식을 구조화하고 함께 축적하는 협업 위키.
하나의 아이디로 모든 Byte 서비스 이용

통합계정 안내

기존 byteexam 등에서 사용하던 계정이 있다면 새로 가입하지 않아도 됩니다. 관리자 확인 후 기존 아이디를 통합계정으로 전환해 드립니다.

01 기존 계정 확인

사용하던 Byte 서비스 이름과 아이디, 표시 이름을 확인합니다.

02 관리자에게 문의

아래 이메일로 통합계정 전환을 요청합니다. 비밀번호는 보내지 마세요.

03 통합계정으로 전환

관리자 확인이 끝나면 기존 아이디를 기준으로 Byte 통합계정을 사용할 수 있습니다.

기존 계정을 통합계정으로 바꾸고 싶나요? 사용 중인 서비스·아이디·표시 이름을 적어 문의해 주세요. 보안을 위해 현재 비밀번호나 다른 개인정보는 메일에 작성하지 마세요.
